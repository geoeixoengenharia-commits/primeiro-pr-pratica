# primeiro-pr-pratica

Repositório de prática para aprender o fluxo de Pull Requests no GitHub.

## Objetivo

Este repositório serve como ambiente de treino para praticar o fluxo completo de contribuição via Git e GitHub:

1. Criar uma branch
2. Fazer uma alteração
3. Abrir um Pull Request
4. Revisar e mesclar (merge)

## Como contribuir

```bash
git clone https://github.com/geoeixoengenharia-commits/primeiro-pr-pratica.git
cd primeiro-pr-pratica
git checkout -b minha-alteracao
# faça suas alterações
git add .
git commit -m "Descrição da alteração"
git push origin minha-alteracao
```

Depois é só abrir o Pull Request pelo GitHub ou via `gh pr create`.
